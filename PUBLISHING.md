# Publication status

Recipe Hunter 0.4.0 is an experimental client-side Fabric mod for Minecraft 26.1.2 and Java 25.
Source is maintained at https://github.com/amdragjakelong2024-rgb/Recipe-Hunter-for-Hypixel-Skyblock.
Successful GitHub Actions builds provide the installable JAR, sources JAR and SHA-256 checksums.

The mod has not been published to Modrinth. No Modrinth or Hypixel approval is claimed.
Code is AI-assisted; the project and NEU data licences must remain with distributions.

There is no background telemetry. Optional external AI requests send the goal summary, observed stats and user diary text only after the user presses Analyze. API keys are session-only, masked, and never part of repository or build artifacts. Local calculations do not require an API key. Provider billing is separate from ChatGPT subscriptions.

See README.md for usage and known limitations and VALIDATION.txt for validation scope.
