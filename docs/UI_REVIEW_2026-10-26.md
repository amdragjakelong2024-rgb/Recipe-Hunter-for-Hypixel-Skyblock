# UI correction build — 26 October 2026

## Reported issues addressed

- `/rh` opens All Recipes. `/rh book` opens saved recipes. Internal navigation does not reopen the book.
- Opening and final screen share the same centered viewport; the enchantment-table renderer's fixed vertical offset is no longer used.
- Search and quantity fields use native screen coordinates. Rendering no longer transforms widget hitboxes independently. Search preserves focus and cursor while filtering; the entire form is not rebuilt on a periodic timer.
- `Hide completed` filters observed finished items and recorded craft history. `Owned only` filters physical finished items only. Neither uses ingredient readiness. The filters do not navigate to another screen.
- Back controls and `Back to all recipes` replace the old Home/Completed navigation. ESC closes the book; there is no Close button.
- Seven HUD ingredient rows; explicit previous/next arrows. Click them with the inventory or chat cursor unlocked. No automatic pages and no source diagnostic text on the HUD.
- `/rh help` lists commands. `/rh current` includes a clickable direct recipe link without opening animation.
- Disabled page arrows cannot advance or trigger transitions at either end, including page 1/1.
- Reference-matched parchment/leather texture, faint Wither watermark, framed controls, boxed search, recipe cards, progress bars and larger headings. Item icons and recipe data remain live Minecraft elements.
